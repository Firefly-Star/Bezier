# Bezier Curve

A C++ implementation of Bézier curve generation and visualization using the Eigen library.

## Features

- Compute points on Bézier curves of arbitrary degree
- Support for multiple curve segments
- Interactive visualization

## Build

Requires premake5 and a C++ compiler. 

```bash
./Build.bat
```

## Dependencies

- Eigen (header-only linear algebra library)
- OpenGL / GLFW (for visualization)
